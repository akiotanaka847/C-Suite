# Board Update Memo

A monthly update is a forcing function for your own thinking, not a status report. The audience is sophisticated and busy. Be specific, be honest, ask for help.

## Format

Total length: 600-900 words. Six sections, in order. No exceptions.

### 1. TL;DR (3 sentences)

- Headline metric move (with direction and magnitude)
- Most important thing that happened
- The single ask, if any

### 2. Key metrics (a table)

| Metric | Last month | This month | Δ | Trailing 3-month trend |
|---|---|---|---|---|
| Net new ARR | | | | ↑/→/↓ |
| Gross churn $ | | | | |
| Cash | | | | |
| Burn (last 3-mo avg) | | | | |
| Runway (months) | | | | |
| Headcount | | | | |
| New customers | | | | |
| Pipeline ($) | | | | |

Add 1-2 company-specific metrics that matter most to YOUR business (activation rate, NPS, gross margin, whatever).

### 3. What went well (3 bullets max)

Specific wins. Names of customers when allowed. No vague self-congratulation.

### 4. What didn't (3 bullets max)

What missed, what broke, what's harder than expected. Investors trust founders who name problems before being asked.

### 5. Asks (numbered, 1-3 max)

Each ask is:
- Specific (the person, intro, advice, or resource needed)
- Time-bound
- Actionable by SOMEONE on the board, not the whole list

If you have no asks, say "No asks this month" — don't manufacture them.

### 6. Looking ahead (one paragraph)

What you'll be focused on next month and the one thing that, if it works, will change the trajectory. End with a sentence-long preview of the next big inflection (close of round, launch, hire).

## Tone

- Direct. No marketing voice.
- Numbers, not adjectives.
- One bolded sentence in the whole memo — the single most important takeaway.
- Don't bury bad news. Open with it if it's significant.

## What NOT to include

- Roadmap details (those belong in board meeting prep, not the monthly memo)
- Slide-style headers
- "Quote of the month" or other padding
- Anyone's salary, in any context, unless approved for disclosure
